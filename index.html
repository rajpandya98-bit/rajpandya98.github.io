Wearable Motion Monitoring System

Clinical Validation & MATLAB Post-Processing

Clinical V&V MATLAB Wearables SaMD

Project Summary

This project was developed with a verification and validation (V&V) mindset to simulate how wearable-based digital health features are evaluated in clinical research environments. The emphasis was on structured data acquisition, MATLAB-based post-processing, and quantitative system evaluation under controlled test conditions, consistent with Software as a Medical Device (SaMD) development.

Rather than prioritizing algorithm complexity, the project focused on signal integrity, noise behavior, threshold-based detection, and repeatable testing, aligning with real-world clinical validation workflows.

Clinical Validation Approach

  • Defined controlled test scenarios representing fall and non-fall motion patterns
  • Executed repeated validation runs to assess consistency and repeatability
  • Evaluated signal stability, threshold behavior, and data integrity
  • Structured activities to mirror small-scale clinical study workflows

MATLAB Post-Processing & Data Analysis

  • Developed MATLAB scripts to post-process accelerometer data from validation runs
  • Performed signal filtering, axis-wise analysis, and threshold evaluation
  • Generated plots and statistical summaries to assess detection consistency
  • Structured scripts as reusable post-processing tools across datasets

System Overview

  • Multi-axis wearable motion sensing using accelerometer-based acquisition
  • Threshold-based event detection for fall-like motion patterns
  • Focus on signal integrity, noise reduction, and repeatable measurements
  • Designed for validation-focused analysis rather than algorithm optimization

Tool Assumptions & Limitations

  • Sensor placement assumed consistent across validation runs
  • Thresholds evaluated under controlled test conditions
  • Dataset limited to simulated scenarios
  • Real-world motion variability may impact detection reliability

Technical & Validation Documentation

  • Documented system architecture and validation methodology
  • Recorded assumptions, limitations, and validation observations
  • Applied verification-style documentation aligned with regulated environments
